# 💰 FinTrack

> **An Offline-First Android-Based Personal Finance and Budget Management System**

FinTrack is a modern **offline-first Android application** designed to help users efficiently manage their personal finances, track income and expenses, monitor monthly budgets, and gain valuable financial insights—all without requiring a continuous internet connection.

The application is being developed using **Kotlin** and **Jetpack Compose**, following the **MVVM (Model–View–ViewModel)** architecture to ensure clean code, maintainability, and scalability. It leverages **Room Database** for secure local data storage, **Hilt** for dependency injection, **Kotlin Coroutines & StateFlow** for asynchronous programming and reactive state management, and **WorkManager** for reliable background tasks such as budget reminders.

FinTrack aims to provide a simple, secure, and user-friendly financial management experience while demonstrating modern Android development practices and software engineering principles.

---

## ✨ Key Features

- 💵 Track income and expense transactions
- 📂 Category-based transaction management
- 📊 Interactive financial dashboard and analytics
- 💰 Monthly budget planning and monitoring
- 🔔 Budget reminder notifications
- 📱 Offline-first architecture
- 🔒 Biometric authentication
- 💳 Bill splitting among multiple participants
- 📩 SMS-based transaction import *(with user permission)*
- 🔍 Search and filter transaction history
- 🌙 Material Design 3 with Dark Mode support
